# Windows Security Log Investigation Lab

# Overview
A beginner cybersecurity home lab using Windows Server 2025 and Oracle VirtualBox to explore Windows authentication events and security logging.

# Objectives
Navigate Windows Event Viewer and the Security log.
Review authentication failure events and available event details.
Document findings and distinguish evidence from assumptions.
Identify appropriate follow-up steps for an authentication event.

# Tools
Windows Server 2025
Windows Event Viewer
Oracle VirtualBox

# Project Report
See Incident Report for the investigation notes, assessment, and recommended next steps.

# Scope
This was a controlled home-lab exercise. It did not involve production systems and did not establish malicious activity.

# Skills Practiced
Windows security logging, basic event analysis, technical documentation, and evidence-based reporting.
